# DJ Deck Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a standalone `dj.html` page with two synthesized decks, a crossfader, EQ, filter, effects and layer pads that a beginner can mix with.

**Architecture:** A pure-logic module (`music.js`) and pattern data (`tracks.js`) feed a Web Audio engine (`engine.js` + `synth.js`): one AudioContext, one look-ahead step scheduler shared by two decks, a per-deck effects chain and a master bus. `djDeck.js` wires the DOM controls to the engine. The page follows the `studio-intro.html` pattern (own HTML entry, own SCSS, "Press to start" gate).

**Tech Stack:** Vanilla JS (ES modules), Web Audio API, SCSS, GSAP (already installed), Parcel, `node --test` for pure logic.

**Spec:** `docs/superpowers/specs/2026-10-20-dj-deck-design.md`

All paths below are relative to `website/` unless they start with `docs/`. Repo root is `coolStudioLanding/`.

## Global Constraints

- Browser floor: Safari/iOS 14, Chrome 87 (`browserslist` in `package.json`; do not touch it). Use `window.AudioContext || window.webkitAudioContext`.
- No Howler, no new npm dependencies. GSAP is allowed.
- No audio before a user gesture; show the "Press to start" screen first (as in `studio-intro.html`).
- Key: A minor pentatonic, semitones `[0, 3, 5, 7, 10]`, root `110` Hz (A2). Tempo range 90–140 BPM, 16 steps per bar.
- All audio parameter changes use `setTargetAtTime` (no clicks). Master limiter is a `DynamicsCompressor`.
- SCSS: BEM (`dj__element--modifier`), variables and `fluid()`/`$bp-phone` from `base.scss`; fonts `streetOfRage` and Poppins.
- Phone width usable: stacked decks, 16 px side gutters, no horizontal scroll. Honour `prefers-reduced-motion`.
- Do not modify existing files with uncommitted edits (`offerSplit.js`, `base.scss`, `caseStudies.scss`, `landing.scss`, `loader.scss`, `offerSplit.scss`, `playerSelect.scss`, `stacked-services.scss`, `sunShine.scss`). `index.html` is not changed in this plan.
- Commits add only the files each task names.

## Review Focus

1. Tempo knob dragged while playing: no step is skipped or doubled, and decks stay aligned.
2. Rapid play/stop toggling: timers and scheduled notes never stack; stop is silent within one step.
3. Crossfader fully to one side: the other deck is silent but keeps its place, so bringing it back is still on the beat.
4. Tab hidden then shown (or a long main-thread stall): no burst of catch-up notes.
5. iOS suspended/"interrupted" AudioContext, start pressed twice, or a drag released outside its control: audio resumes, nothing double-initialises, no control gets stuck.

### Task 1: Pure music helpers

**Files:**
- Create: `src/assets/js/dj/music.js`
- Test: `tests/dj/music.test.mjs`

**Interfaces:**
- Produces (all named exports):
  - `SCALE: number[]` = `[0, 3, 5, 7, 10]`, `ROOT_HZ: number` = `110`, `BPM_MIN = 90`, `BPM_MAX = 140`
  - `noteToHz(degree: number, octave?: number): number` — degree indexes the scale and wraps into higher octaves every 5; `octave` shifts by 12 semitones.
  - `clampBpm(n: number): number` — clamps to 90–140; non-finite input returns `120`.
  - `stepDuration(bpm: number): number` — seconds per 16th note (`60 / clampBpm(bpm) / 4`).
  - `crossfadeGains(pos: number): { a: number, b: number }` — equal power, `pos` clamped 0–1, `a = cos(pos·π/2)`, `b = sin(pos·π/2)`.
  - `sweepToFilter(v: number): { type: 'off' | 'lowpass' | 'highpass', freq: number }` — `v` clamped −1..1; `|v| < 0.04` is `off`; negative is lowpass falling exponentially from 20000 Hz to 200 Hz at −1; positive is highpass rising exponentially from 30 Hz to 6000 Hz at +1.
  - `eqToDb(v: number): number` — `v` clamped −1..1; negative maps linearly to −24 dB at −1, positive to +6 dB at +1.

- [ ] **Step 1: Write the failing tests** in `tests/dj/music.test.mjs` (`node:test`, `node:assert/strict`): `noteToHz(0) === 110`; `noteToHz(5) === 220` (octave wrap); `noteToHz(1)` is `110·2^(3/12)` within 1e-9; `noteToHz(0, 1) === 220`; `clampBpm(60) === 90`, `clampBpm(200) === 140`, `clampBpm(NaN) === 120`; `stepDuration(120) === 0.125`; `crossfadeGains(0)` → `{a:1,b:0}`, `crossfadeGains(1)` → `{a≈0,b:1}`, and `a² + b² ≈ 1` at 0.3; `sweepToFilter(0).type === 'off'`, `sweepToFilter(-1)` → lowpass at 200 Hz, `sweepToFilter(1)` → highpass at 6000 Hz, `sweepToFilter(5)` same as `sweepToFilter(1)`; `eqToDb(-1) === -24`, `eqToDb(1) === 6`, `eqToDb(0) === 0`.
- [ ] **Step 2: Run** `node --test tests/dj/` from `website/`. Expected: FAIL (module not found).

### Task 3: Scheduler (look-ahead clock)

**Files:**
- Create: `src/assets/js/dj/scheduler.js`
- Test: `tests/dj/scheduler.test.mjs`

**Interfaces:**
- Consumes: `stepDuration`, `clampBpm` from `music.js`.
- Produces: `createScheduler(opts): { start(): void, stop(): void, tick(): void, readonly running: boolean, readonly nextStepIndex: number }` where `opts = { ctx: { currentTime: number }, getBpm: () => number, onStep: (stepIndex: number, time: number) => void, lookahead?: number /* 0.1 s */, intervalMs?: number /* 25 */, setTimer?: typeof setInterval, clearTimer?: typeof clearInterval, maxCatchUp?: number /* 0.25 s */ }`. `stepIndex` cycles 0–15. `start()` begins at `ctx.currentTime + 0.05`. `tick()` is the body of the timer, exposed so tests can drive it.

- [ ] **Step 1: Write failing tests** with a fake `ctx` whose `currentTime` the test advances, calling `tick()` directly:
  - at 120 BPM, advancing 1 s yields 8 steps at times 0.05, 0.175, … with indexes 0..7, each exactly once;
  - changing `getBpm` from 120 to 140 mid-run: steps already emitted keep their times, later steps use the new `stepDuration`, none skipped or doubled (indexes contiguous);
  - `start()` twice creates one timer (inject counting `setTimer`); `stop()` clears it and a later `tick()` emits nothing;
  - stop then start in rapid succession leaves exactly one active timer and restarts at index 0;
  - jump `currentTime` forward by 10 s (hidden tab): the next `tick()` emits no steps in the past — it re-anchors to `currentTime + 0.05` instead of replaying, emitting at most `maxCatchUp / stepDuration` steps.
- [ ] **Step 2: Run** `node --test tests/dj/scheduler.test.mjs`. Expected: FAIL.
- [ ] **Step 3: Implement** `scheduler.js`. Step duration is read from `getBpm()` each time a step is scheduled (so tempo changes affect subsequent steps only). If `nextTime < ctx.currentTime - maxCatchUp`, re-anchor `nextTime` to `ctx.currentTime + 0.05` and keep `nextStepIndex` unchanged.
- [ ] **Step 4: Run** the tests. Expected: pass.

### Task 5: Engine (decks, master bus, effects)

**Files:**
- Create: `src/assets/js/dj/engine.js`
- Test: `tests/dj/engine.test.html` (browser harness using `OfflineAudioContext`)

**Interfaces:**
- Consumes: `createScheduler`; `TRACKS`/`getTrack`/`LAYERS`; `synth` voices; `noteToHz`, `clampBpm`, `crossfadeGains`, `sweepToFilter`, `eqToDb`.
- Produces: `createEngine(opts?: { audioContext?: AudioContext, destination?: AudioNode, bpm?: number }): Engine`, where
  ```
  Engine = {
    ctx: AudioContext,
    decks: [Deck, Deck],                       // index 0 = A, 1 = B
    analysers: { a: AnalyserNode, b: AnalyserNode, master: AnalyserNode },
    setBpm(bpm): number,                       // returns clamped value
    getBpm(): number,
    setCrossfade(pos: number): void,           // 0 = all A, 1 = all B
    drop(): void,                              // bass+drums cut for one bar, then re-enter
    setFx(x: number, y: number): void,         // x = delay send, y = reverb send, both 0–1
    resume(): Promise<void>,
    suspend(): Promise<void>,
    destroy(): void
  }
  Deck = {
    setTrack(id: string): void, readonly trackId: string,
    play(): void, stop(): void, readonly isPlaying: boolean,
    setVolume(v: number): void,                // 0–1
    setEq(band: 'low' | 'mid' | 'high', v: number): void,   // −1..1 via eqToDb
    setFilter(v: number): void,                // −1..1 via sweepToFilter
    setLayerMuted(layer: string, muted: boolean): void,
    isLayerMuted(layer: string): boolean
  }
  ```
  Both decks are driven by the single shared scheduler, so they are always on the same step. Decks that are stopped emit nothing; a playing deck keeps stepping even when the crossfader silences it (Review Focus 3).

- [ ] **Step 1: Write the browser harness** `tests/dj/engine.test.html` using an `OfflineAudioContext` passed as `audioContext` and a fake timer where possible; assertions printed as PASS/FAIL lines: after `decks[0].play()` and 2 s of offline render the master analyser/render output has non-zero energy; with `setCrossfade(1)` deck A contributes silence (render with only deck A playing: peak < 0.001) yet `decks[0].isPlaying` stays true; `decks[0].setLayerMuted('bass', true)` reduces low-band energy versus unmuted; `play(); stop(); play(); stop()` ×20 leaves one scheduler timer (expose via a debug counter `engine._debug.timers`); `setBpm(500)` returns 140; `destroy()` leaves `_debug.timers === 0`.
- [ ] **Step 2: Run it** in the browser. Expected: FAIL (module missing).
- [ ] **Step 3: Implement** `engine.js`. Chain per deck as in the spec (layer gains → low shelf / peaking mid / high shelf → sweep `BiquadFilter` bypassed when `type === 'off'` → deck gain → crossfade gain → master). Master: delay + generated-noise-decay `ConvolverBuffer` reverb sends (reverb impulse as in dkton.at: 1.9 s, `(2r−1)(1−i/n)^2.6`), `DynamicsCompressor` limiter, then `destination`. Analysers: one per deck pre-crossfade, one on master. Use `setTargetAtTime(value, now, 0.05)` for every parameter. The scheduler `onStep` loops over playing decks and layers, calling the synth voices with `noteToHz`. `drop()` mutes bass+drums gain for 16 steps then restores via the same gains. Support `webkitAudioContext` when constructing.
- [ ] **Step 4: Run** the harness. Expected: all lines PASS.
- [ ] **Step 5: Commit** — `git add src/assets/js/dj/engine.js tests/dj/engine.test.html && git commit -m "feat(dj): audio engine"`
